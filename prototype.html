Agent Delegation

Allow your AI agent to create scoped access grants on your behalf — so it can call identity-gated APIs autonomously.

🤖 Smart Account Signer Delegation

To enable your agent to call identity-gated APIs without your manual approval each time, you can delegate idOS signing authority to a smart account (e.g. ERC-4337). The agent gets a scoped session key that can only create time-limited dAGs — never decrypt your data or transfer funds.

How it works

1. You deploy or connect an ERC-4337 smart account
2. You sign a delegateAGSigning transaction scoping: which credential types, which APIs, max TTL per dAG, and a session expiry
3. Your agent receives a session key that can call idOS.createDelegatedAG() for approved scopes
4. Each dAG is scoped, time-limited, and logged to this dashboard
5. You can revoke all delegation instantly from here
