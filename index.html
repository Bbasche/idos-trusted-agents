PRODUCT BRIEF Identity-Gated API Marketplace

idOS Trusted Agents

An identity-gated API marketplace where AI agents pay with USDC (x402) and prove their principal's identity through idOS — once. KYC, proof-of-personhood, and uniqueness credentials are portable, private, and reusable across every API in the ecosystem.

The Problem
x402 solved API payments.
Identity breaks every time.
AI agents can pay for any API with stablecoins. But when those APIs need KYC, proof-of-personhood, or Sybil resistance — the agent hits a wall. Worse: every API demands re-verification from scratch. Trusted Agents fixes both.
🔐

Zero-PII Compliance

APIs verify credential hashes — never seeing, storing, or decrypting personal data. Identity is confirmed before payment settles. All access grants auto-expire.

♻️

Verify Once, Reuse Everywhere

One KYC credential powers every API. A PoP check from one service satisfies the next. No re-verification, no new accounts, no duplicated effort.

🤖

Agent-Native + Delegated

Agents create scoped dAGs autonomously via smart account delegation (ERC-4337). Session keys are limited to creating time-limited access grants — never decrypting data.

For API Operators
Choose your identity gate
API providers integrate a single middleware and choose from a menu of compliance levels. Each level maps to an idOS credential type. All verification happens before payment settlement.

POP Proof of Personhood

Verify a real human is behind the request. Prevents bot abuse and Sybil attacks. Based on FaceSign liveness — no ID documents needed. Lightest-touch compliance.

UNIQUE Uniqueness

Enforce one account per human. Combines PoP with on-chain uniqueness checks. Ideal for airdrops, voting, and fair distribution where Sybil resistance is critical.

KYC KYC — Credential Hash Only

Require a KYC credential issued by a trusted issuer (e.g. via idOS Relay). API verifies the credential hash on idOS — no access grant needed. The API never sees PII. Sufficient when you just need assurance that the user passed KYC somewhere trusted.

KYC+AG KYC — With Access Grant

Full KYC with a scoped, time-limited access grant that allows the API provider to re-verify the credential. Required when regulatory obligations demand the ability to re-check identity (e.g. fiat on/off-ramps, financial services).

// Example middleware configuration for an API operator
x402.paymentMiddleware({
  "GET /v1/report": {
    price: "$0.50",
    network: "base",
    identity: {
      provider: "idOS",
      level: "kyc", // "pop" | "unique" | "kyc" | "kyc-ag"
      accepted_issuers: ["idOS Relay"],
      require_ag: false // true for kyc-ag level
    }
  }
})
Request Flow
Identity first. Payment second.
Identity verification always completes before payment settles. If the credential check fails, no USDC is transferred — no refunds needed, no failed transactions.
📡
STEP 1

Request

🚧
STEP 2

402 Response

Server returns payment terms + identity requirements

🪪
STEP 3

Verify Identity

dAG + credential hash verified on idOS before payment

💰
STEP 4

Settle Payment

x402 USDC payment settles only after identity confirmed

✅
STEP 5

Resource Served

API responds. dAG auto-expires. No PII stored.

Architecture
System components + types
Every component in the system is labeled with what it actually is — client library, server middleware, smart contract, or hosted service.
The Stack
Open protocols + idOS identity services
The system separates open, vendor-neutral protocols from idOS-specific identity services. API operators depend only on the open layer; identity services are pluggable.
🔓 Open Protocols
⚡
x402 Protocol

HTTP-native stablecoin micropayments. USDC on Base. Coinbase-backed open standard. npm: x402-middleware

🔗
Base L2

Coinbase EVM L2. Sub-cent gas, instant USDC settlement. ERC-20 USDC contract

🪪
idOS Network

Decentralized credential storage + access management on Kwil chain. Open-source, chain-agnostic. npm: @idos-network/sdk

📋
W3C Verifiable Credentials

Industry-standard credential format. Interoperable, portable, cryptographically verifiable.

🛡️ idOS Identity Services
😊
idOS FaceSign

Biometric liveness authentication. Derives encryption keys from face scan in secure enclave. <5s. Cross-device. idOS hosted service

🔄
idOS Relay

KYC orchestrator. Routes to providers (Sumsub, etc.), issues credentials, revokes own access, purges all data. idOS hosted service

🤖
Agent Delegation

ERC-4337 smart account integration. Scoped session keys for autonomous dAG creation. smart contract + SDK

📡
Trusted Agents Marketplace

Service catalog, credential management, activity logging, agent terminal. web app (proposed)
